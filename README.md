## Overview

When the Vortex Platform launched on May 4, 2026, the native experience was minimalist and bright, offering limited functionality beyond basic profile interaction and map joining. Crucially, it lacked dark mode support and deep interface customization.

Created the very next day, **BetterVortex** was built to provide the customization options users were asking for:

- **Enhanced User Control & Freedom:** Tailor the platform interface to your preferences.
- **Visual Comfort:** Built-in Dark Mode and custom themes to reduce eye strain.
- **Quality-of-Life Enhancements:** Practical UI additions and shortcut navigation directly into the header.

## Installation

See the [Full Installation Guide](.github/MISC.md) for detailed platform notes.

1. **Download:** Head to the [Releases](https://github.com/Klingri/BetterVortex/releases) page and grab the latest `Source code (zip)`.
2. **Extract:** Unzip the archive to a permanent folder on your system.
3. **Open Extensions Page:** Navigate to your browser's extension manager:
   - **Chrome:** `chrome://extensions/`
   - **Edge:** `edge://extensions/`
   - **Brave:** `brave://extensions/`
   - **Vivaldi:** `vivaldi://extensions/`
   - **Opera / OperaGX:** `opera://extensions/`
   - **Arc:** `arc://extensions/`
   - **Helium:** `helium://extensions/`
   - **Yandex:** `browser://extensions/`
   - **Firefox:** `about:addons`
4. **Developer Mode:** Enable the **Developer mode** toggle (top right on Chromium browsers).
5. **Load Extension:** Click **Load unpacked** and select your extracted directory.

## Known Limitations

- **No Auto-Updates:** Manual re-installation via the Releases page is required for updates.
- **Upstream Changes:** Platform updates to Vortex may occasionally break visual element selectors.
- **Theme Optimization:** Interface components are optimized primarily for dark mode aesthetics.
- **Browser Compatibility:** Best experienced on Chromium-based browsers; full compatibility with Firefox or legacy builds is not guaranteed.
